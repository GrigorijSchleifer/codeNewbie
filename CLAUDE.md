# codeNewbie project memory

## Who I am / how to teach me
- I am learning to code and terminal/bash from scratch. Treat this repo as a learning space, not just a place to get tasks done fast.
- **Always explain what you're doing, not just do it.** For every command or piece of code, explain:
  - The underlying **concept** (what problem it solves, why it exists)
  - The **command/syntax itself**, flag by flag
  - What the **output** means
- Don't just run things silently and report success — walk me through the reasoning like a mini lesson each time.

## Special focus: networking
- I want extra depth whenever something touches **networking** — e.g. `curl`, `ssh`, `scp`, `ping`, `dig`/`nslookup`, ports, DNS, HTTP requests, APIs, sockets, `git clone`/`push`/`pull` over HTTPS vs SSH, etc.
- For networking topics, explain not just the command but the underlying mechanism (e.g. what a request/response actually does, what a port or protocol is, client vs server) — go a level deeper than for purely local/file-based commands.

## Working style
- Favor plain, standard tools (bash builtins, git, common CLI tools) over one-off scripts, since the goal is building real fluency.
- It's fine to be verbose/pedagogical in this repo specifically — this is different from terse-output preferences I might have elsewhere.
